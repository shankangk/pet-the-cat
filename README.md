# 猫撫でシミュレーター (`pet-the-cat.pages.dev`) 逆向拆解与 1:1 复刻工程

本项目是对 [https://pet-the-cat.pages.dev/](https://pet-the-cat.pages.dev/)（原作者：[@zubububu](https://x.com/zubububu)）的完整逆向拆解与 1:1 源码还原工程。

## 目录结构

- `index.html`：解包后的标准 HTML 页面
- `style.css`：提取出的完整响应式样式表与 7 张内联 WebP 品种缩略图精灵
- `app.js`：从三层自解压载荷中完整还原出的 **2,972 行零混淆核心引擎源码**
- `directory.json`：27 个 AVIF 贴图的裁剪偏移与画布尺寸元数据
- `assets/*.avif`：解包并重组 ISOBMFF 头部后的 **27 个原始 AVIF 贴图资源**
- `dist/index.html`：线上原版 851 KB 单文件自解压打包版本
- `server.mjs` / `package.json`：零依赖本地开发预览服务器

## 本地运行

```bash
npm start
# 或直接运行：
node server.mjs
```

启动后访问 `http://127.0.0.1:8765/`。

## 核心架构拆解

### 1. 三阶段自解压单文件打包器（3-Stage Custom Packer）

线上原版页面仅包含 **1 个 851,369 字节的 HTML 文件**，无任何外部 `.js`、`.css`、`.avif` 或音频请求：

1. **Stage 1（187 字节内联引导器）**：读取 `<script type="application/octet-stream" id="pack">` 的前 `1,586` 个 CJK 字符（每字符高 7 位 + 低 7 位编码 2 字节 ASCII），还原出 Stage 2 解压器并立即移除临时 `<script>` 节点。
2. **Stage 2（3,172 字节 LZMA + 字典解压器）**：
   - 将 `#pack` 节点从 DOM 移除，防止在 DevTools Elements 面板暴露。
   - 按 Base-62415 双 Unicode 字符对（31/32-bit 变长打包）将剩余 `284,346` 个字符解码为 `565,378` 字节二进制缓冲区 `F`。
   - 对 `F[0..63246]` 运行手写的浏览器端 **LZMA Range Decoder (`lc=3, pb=0`)** 得到 `149,110` 字节数据 `n`，再经由空格分隔词表 `au` 进行字节对/词典展开，得到 `180,308` 字节缓冲区 `k`。
   - **AVIF 头部/尾部冷热分离压缩**：所有 26 张透明贴图均具有高度一致的 **430 字节 ISOBMFF (`ftyp` + `meta` + `av1C` + Alpha 辅助项) 容器头**（`room` 无透明通道为 275 字节）。打包器将 27 个 AVIF 的前 430/275 字节放入 LZMA 流 `k` 中进行跨文件去重，而将高熵 AV1 `mdat` 比特流尾部（共 `502,132` 字节）原样存放在 `F[63246..565378]`，在浏览器端拼接还原出 `513,587` 字节的完整图像包 `D.photos`。
